# Командный центр Ядро — Образовательный проект «Смысл учёбы»

Интерактивная система сопровождения 5-дневного выезда для детей 8–17 лет (Школа Мужества).

## Возможности
- Древо технологий развития города (14 узлов по 5 дням)
- Терминал передачи детского опыта и обучения нейросети Ядро
- Живой диалог с Ядром (до и после обучения) через OpenRouter AI
- Таблица и прогресс районов города

Проект опубликован на GitHub Pages.
